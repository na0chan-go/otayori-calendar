# Requirements

## Functional Requirements

### 認証

- ユーザーはGoogleアカウントでログインできる
- ユーザーはGoogleカレンダー登録権限を許可できる

### おたより管理

- ユーザーは画像をアップロードできる
- ユーザーはアップロードした画像を一覧表示できる
- ユーザーはOCR結果を確認できる
- ユーザーはおたよりごとの抽出・確認・登録状況を確認できる
- 予定候補があるおたよりを再抽出する場合は、重複候補が増える可能性を事前に確認する

### 予定抽出

- システムはOCR結果から予定候補を抽出する
- 抽出対象は以下とする
  - 行事名
  - 日付
  - 時間
  - 場所
  - 持ち物
  - 提出期限
  - 注意事項

### 予定確認

- ユーザーは抽出された予定候補を確認できる
- ユーザーは予定内容を編集できる
- ユーザーは持ち物と提出期限を予定情報と分けて確認・編集できる
- ホーム画面で直近の持ち物と提出期限を確認できる
- ユーザーは不要な候補を除外できる
- ユーザーは除外・一括確認・一括除外を直後に取り消せる
- 取り消しはGoogleカレンダーと未連携の状態間に限定し、操作後に状態が変わった候補は上書きしない

### Googleカレンダー連携

- ユーザーは確認済み予定をGoogleカレンダーへ登録できる
- 持ち物と提出期限はGoogleカレンダーの説明欄へ読みやすく反映する
- 登録前に、同日かつタイトルが一致・類似する登録済み予定や選択中候補を警告する
- 重複警告後も、ユーザー判断で登録続行または候補除外を選べる
- 登録済み予定は再登録されない
- Google Calendar Event IDを保存する

## Non-functional Requirements

- 誤登録防止のため、AI抽出結果は自動登録しない
- 個人情報を含む画像を扱うため、ユーザー単位でアクセス制御する
- Google OAuthのトークンは安全に保存する
- 予定抽出処理に失敗しても、手入力で登録できる
- 外部API障害時でも、抽出済み候補や手入力予定を保持できる

## Status Definition

| status | 意味 |
|---|---|
| draft | AI抽出直後 |
| confirmed | ユーザー確認済み |
| registered | Googleカレンダー登録済み |
| ignored | ユーザーが除外 |
| failed | 登録失敗 |
| deleted | Googleカレンダー上で削除済み |
