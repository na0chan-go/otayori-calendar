# Roadmap

## Phase 1: Calendar Integration MVP

- Googleログイン
- 手入力予定のGoogleカレンダー登録
- 登録済みイベントID保存
- 重複登録防止

## Phase 2: Letter Upload

- おたより画像アップロード
- 画像一覧
- OCR結果保存
- 原本画像表示

## Phase 3: AI Extraction

- OCR / AIによる予定候補抽出
- 抽出結果の確認画面
- 予定編集
- confidence表示

## Phase 4: Usability

- 持ち物抽出
- 提出期限抽出
- 明日の予定表示
- 登録済み予定一覧

## Phase 5: Portfolio Enhancement

- デモ動画
- 技術記事
- README改善
- アーキテクチャ図
- ER図
